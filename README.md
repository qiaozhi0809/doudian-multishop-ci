# 抖店多店铺管理后台

本机运行的抖音小店多店铺管理工具：把订单、售后、商品、库存、资金、对账聚合到同一个界面，
替代「逐个登录每个店后台、重复操作」的日常劳动。

数据与登录态全部留在本机，不经过第三方服务器。

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS 4 + Arc 组件库 |
| 后端 | Python 3.12 + FastAPI + curl_cffi |
| 存储 | SQLite（WAL） |
| 打印 | 抖店官方打印组件（本地 WebSocket） |
| 登录 | Playwright（首次扫码，之后走协议） |

## 模块范围

**已定义（只读）**
- 订单：列表、筛选、状态计数、地址解密
- 售后：列表、详情、状态计数、待办队列
- 商品 / 库存：列表、计数、库存概览
- 资金：待结算、账单、保证金
- 跨店对账：快照比对、三类异常

**已定义（写操作）**
- 批量备注、取号、发货前检查、发货、取号并发货
